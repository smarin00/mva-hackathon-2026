# Candidate gene panel — MVA Hackathon 2026
#
# Purpose: restrict compute-heavy, high-sensitivity analyses to genes where a
# second causal allele could plausibly hide. Used for:
#   - mosaic-aware calling (Mutect2), which is too slow genome-wide
#   - read-backed phasing (WhatsHap)
#   - targeted review of non-PASS vendor calls
#   - the rare-intronic splice sweep (SpliceAI / Pangolin)
#
# Scope rationale: the proband's phenotype is chromosomal-instability driven.
# The panel therefore covers (1) established MVA genes, (2) the machinery whose
# failure produces missegregation, and (3) differential-diagnosis genes with
# overlapping phenotypes (microcephaly, growth restriction, cancer predisposition).
# Category 3 is deliberately included so that a competing explanation would be
# detected rather than missed by a narrow panel.
#
# Symbols are current HGNC. Genes not found in the Ensembl GTF are reported by
# bin/build_panel.py and must be checked for renaming before the panel is used.
